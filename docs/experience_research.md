# 教师示范、学生试验与经验整理：依据和实现边界

采用已有方法中适合本项目的部分，不声称完整复现论文，也不把它们的实验结果当作本机械臂的性能保证。

[DROC：Distilling and Retrieving Generalizable Knowledge for Robot Manipulation via Language Corrections](https://arxiv.org/abs/2311.10678) 研究从在线语言纠正中提取可检索知识；其[项目页](https://sites.google.com/stanford.edu/droc)给出任务和对照实验。我们采用“纠正发生在哪一步、针对什么失败、证据是什么”的记录方式，不直接把教师一句话提升为普遍规律。当前没有训练或接入论文的视觉检索模型。

[MimicGen 官方文档](https://mimicgen.github.io/docs/tutorials/datagen_custom.html)明确需要环境接口提供末端和物体位姿；任务分段可依赖终止信号或人工标注。[数据生成类说明](https://mimicgen.github.io/docs/modules/datagen.html)给出分段轨迹、物体位姿、目标位姿和夹爪动作的结构。因此这里采用显式阶段/接触分段，并在有可信米制定位时转换成物体相对关键点。没有目标定位、接触证据或可达性检查时，不迁移整条轨迹。本版本没有实现 MimicGen 数据合成、自动标注或行为克隆训练。

[robomimic 数据说明](https://robomimic.github.io/docs/datasets/overview.html)把环境元数据、状态、动作、观测和结束信号组织为逐次示范。我们保留同样的时间与来源关联原则，但当前使用 JSON 事件和独立原始文件，不声称它们已经是可直接训练的 robomimic HDF5 数据集。后续转换器必须明确采样率、动作含义、坐标系和对齐规则。

[Voyager](https://voyager.minedojo.org/)在 Minecraft 中使用可执行技能库及反馈驱动的程序改进；它的环境与实体机器人不同。这里借用“方法有代码、来源和可检索说明”的组织方式，发布权仍归维护者，不由学生自动增长技能库。规划检索先检查适用条件，之后才比较文本相似度。

[Reflexion](https://arxiv.org/abs/2303.11366)使用任务反馈和文字反思影响后续尝试。我们只保留其“事后反馈单独存储”的思路：观察事实、失败结果和原因猜测分栏；猜测始终是 unverified，直到维护者拿新证据核对。文字反思本身不是因果证明，也不能替代接触与几何测量。

## 现已实现

`flip_pipeline/experience.py` 实现独立事件校验、证据字节哈希、显式教师分段、物体相对关键点计算、学生失败前缀及重试保留、教师待处理请求、维护者审阅/发布/撤销、先适用范围后词重合的检索。全部为确定性离线程序，不会发起动作或联网调用。

## 尚未实现，也不伪装成已完成

视频自动阶段识别、学习接触分类器、从少量示范自动合成可执行轨迹、训练模仿策略、语义/视觉向量检索和 Astra 服务发送适配器都不在本实现内。unknown 风险交给现有人工渠道或真正接入后的教师；生成 pending 文件不能当成已经获得指导。原始公开对话、代码和工具事件保存；不索取或提取模型隐藏推理。

审核名单与状态机只约束程序正常使用，不构成防恶意进程的权限边界。原始文件应封存，发布目录由维护者控制。即使示范被审核，执行前仍需当前场景验证；这里不生成“安全重放”保证。
