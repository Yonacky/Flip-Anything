# 分工

DS 执行实验并准备原始图像、动作回执、测量、简短依据、失败恢复、人工介入与结果。它可以提出疑点，不能把解释升级成技能，也不负责经验分类、发布或撤回。

Codex 从学生 logs/tasks/*/materials.json 读取材料，核对完整原始过程，再决定修改哪部分。技能库维持翻转目标、可选方案、操作工具和具体案例的区别；设备资料单独管理。反证、验证范围、修改与发布由 Codex 负责。

每次发布保留源文件与哈希。学生旧任务保留当时版本，不改写其结果；历史候选不自动成为新版本的知识。一次成功只支持已观察的条件。

当前更新仅改变新学生工作区。原 ds_control 的对照环境不修改。观察质量、接触判定和设备几何仍需验证，不能因整理了说明就声称已有通用能力。
