## 先读哪些材料

先读 `skill.md`、`AGENTS.md`、`OPERATIONS.md`，然后读 [2026-10-18 案例](../logs/experiments/ds_control/TASK_RECORD_20261018_DS.md)。优先看失败修正、自标定、目标定位和动作序列，知道上次怎样摆脱错误；不需要先遍历所有历史脚本。

该案例整个过程有人工介入。约 20 分钟指重摆后的成功阶段，不包括此前过量接近和用户重置；最后也有用户确认。目标仍是本轮自行完成，不能把上一轮的帮助当作当前已发生的事实。

## 上次有效的方法顺序

先获得完整视野与可靠深度。上次近距深度很差，改变观察距离后才获得足够罐身点；具体距离不是本轮常数。需要时复用已经实现的安装关系估计方法，用不同观测验证，避免在三角化、尺度比、平面法向等新方法间无约束跳转。

用现场观测定位当前物体，选取兼容翻转、落放和退出的抓取位置；上次中位抓取后发现落放净空不足，改为低位抓取才完成。低位是候选方法，不是所有物体的固定抓点。夹稳后试提，分步翻转，再依据当前物体与桌面关系落放。按当前 skill 的支撑判据释放并退出，观察独立站立。历史中按估计小间隙松爪虽取得成功，不构成新物体未知间隙释放的通用规则。

## 本轮记录与权限

使用现有 `robot.ps1`，不要求新框架的 run/assess、episode、候选提取或 export。原始图像和动作回执由执行器记录。阶段只简短报告动作与依据；结束时在本轮 run 写 `TASK_RECORD.md` 与 `outcome.json`，区分成功、失败、未完成、用户中止及人工介入。

运行环境使用父目录 `.venv`。PowerShell 入口统一使用 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\robot.ps1 <命令>`，不假设存在 pwsh。硬件 start 使用宿主后台功能，等待初始采样完成后再操作。设备权限拒绝时沿宿主正式授权流程处理，不重复更换驱动或修改全局权限。

本轮禁止并行占用相机和机械臂。启动检查既要看本目录，也要确认另一工作区没有活动会话。控制器配置如出现矛盾，先核对读数是否有效、是否已刷新，不能仅据启动时的 SDK 初值宣布配置被重置；不自动修改 TCP、负载或保护设置。
