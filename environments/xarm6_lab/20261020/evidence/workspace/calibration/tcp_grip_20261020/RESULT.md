# 本场景夹持TCP标定结果

结果文件：tcp_calibration_result.json。软件夹持参考点相对当前控制器TCP为 [0, 1.86, -16.99] mm；坐标轴沿用控制器工具轴，tool-X=0为定义平面。控制器已有174mm偏置保持不变。这个参考点描述本次有效的深夹持位置，不是把夹爪指腹中心重新定义，更不是求出了所有法兰误差。

首次在TCP高度90mm夹持保持，位置寄存器84；根据标定变换，在100mm高度重新接近并夹持，位置83。两次持续接触均通过。重复测得参考点差 2.73 mm，采用5mm工程余量；该余量不等于认证的绝对精度。未抬升、未做持物旋转试验。

几何来自静止多视角SIFT匹配、已知机械臂位移三角化、稳健圆柱拟合和实际夹持轮廓。当前估计罐径56.25mm；不再将58mm名义尺寸当实物真值。当前场景相机旋转拟合另留一张上移20mm的图像验证：误差中位1.18px，95%为1.94px。旧标定板三张保留样本也已复算，但没有替换全局手眼档案；局部修正及原档案有分别的来源。

第一次浅夹推走罐子的失败、错误轮廓、退化三角化、一次50mm横移在运动前被关节步长限制拒绝，以及用户恢复确认均保留。被拒绝任务未复活，新采集任务关联前一任务；没有放宽限值。原始图片、深度、命令和回执在同名run的logs/experiments/ds_control目录。
